# 柚课日历微信小程序

使用微信开发者工具导入本目录。支持月历、周课表、日程、记账、壁纸、倒计时/正计时学习任务，以及学习时间与收支趋势统计；专注/休息时长直接在计时任务页面设置。新用户首次进入时日历为空。

智能课表导入不依赖项目自建后端。用户在“日历设置”中选择模型服务商，并填写自己的 API Key、接口地址和模型名称。OpenAI、Gemini、Claude 支持直接提交 PDF；DeepSeek、Kimi、通义千问、智谱 GLM、SiliconFlow 和自定义 OpenAI 兼容接口通过粘贴课表文本解析。

API Key 仅保存在小程序本地；课表内容会直接发送给用户选择的模型服务商。正式发布前，必须在微信公众平台为计划支持的服务商配置 `request` 合法域名。
