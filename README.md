# 西柚日历 · SWU Campus Calendar

面向西南大学学生的双端校园日历，包括微信原生小程序与响应式单页面网页版。课表采用本地文件导入，不收集或保存西大账号信息。

## 项目结构

```text
swu-campus-calendar/
├─ 1-小程序源码/     微信原生小程序（WXML + WXSS + TypeScript）
├─ 2-网页版源码/     单页面响应式网页（HTML + CSS + JavaScript）
└─ 3-课表模板/       JSON/CSV 导入模板与字段说明
```

## 主要功能

- 月历、周课表和教学周导航
- 课程、考试、作业、活动与个人日程统一展示
- 日程新增、查询、修改、删除和完成状态
- 时间冲突检测
- 教务课表文件导入与本地解析（JSON、CSV、TXT、制表符）
- 导入后课程编辑、颜色和学期节次自定义
- 校园记账：收入/支出、分类统计、编辑删除
- “下一项安排”提示
- 番茄钟、专注任务和每日专注统计
- 预设主题、自定义壁纸、主题色与卡片透明度
- 网页版 JSON 备份和 ICS 日历导出
- 手机、平板和桌面响应式适配
- 统一校园风格 SVG 图标集（`assets/icons.svg`）

## 快速体验

### 微信小程序

使用微信开发者工具导入 `1-小程序源码`。项目默认使用测试 AppID，正式发布前请在开发者工具中替换为自己的 AppID。

### 单页面网页版

直接打开 `2-网页版源码/index.html`，或在该目录运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

课表导入教程：先访问西大办事大厅 `https://ywtb.swu.edu.cn/new-office-hall-pc/index.html#/`，完成统一身份认证后打开“教务系统 → 我的课表/个人课表”，选择学年和学期并导出 PDF。网页版可直接选择 PDF 自动提取；小程序请用 WPS 打开 PDF 复制表格后粘贴，或另存为 CSV 再导入。也可以直接粘贴带表头的表格文本。

> 本项目不提供账号密码登录后端，所有课表和账目数据只保存在当前设备。
