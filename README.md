# 西柚日历 · SWU Campus Calendar

面向西南大学学生的双端校园日历，包括微信原生小程序和响应式单页面网页版。项目从教师指定的原仓库提交 `cca2e81730ef51c039b3a89d0d3c80b34d7307ca` 开始开发。

## 项目结构

```text
swu-campus-calendar/
├─ 1-小程序源码/     微信原生小程序（WXML + WXSS + TypeScript）
└─ 2-网页版源码/     单页面响应式网页（HTML + CSS + JavaScript）
```

## 主要功能

- 月历、周课表和教学周导航
- 课程、考试、作业、活动与个人日程统一展示
- 日程新增、查询、修改、删除和完成状态
- 时间冲突检测
- 西大远端课表同步适配器与离线缓存
- “下一项安排”提示
- 番茄钟、专注任务和每日专注统计
- 预设主题、自定义壁纸、主题色与卡片透明度
- 网页版 JSON 备份和 ICS 日历导出
- 手机、平板和桌面响应式适配

## 快速体验

### 微信小程序

使用微信开发者工具导入 `1-小程序源码`。项目默认使用测试 AppID，正式发布前请在开发者工具中替换为自己的 AppID。

### 单页面网页版

直接打开 `2-网页版源码/index.html`，或在该目录运行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 远端课表同步

前端不直接调用西大教务系统，而是请求用户自行部署并信任的后端：

```text
POST {backendUrl}/api/swu/schedule
```

请求包含学号、统一认证密码、学年和学期；密码仅用于当次请求，不会写入前端持久化存储。响应支持 `courses`、`schedule` 或 `res` 数组。前端能够将星期、教学周和节次转换成日历事件。

> 请勿把真实账号、密码、Cookie 或 Token 提交到 Git 仓库。
