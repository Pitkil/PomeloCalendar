# 西柚日历 · SWU Campus Calendar

西南大学校园日历，包含微信原生小程序、单页网页版与智能 PDF 课表解析服务。

```text
swu-campus-calendar/
├─ 1-小程序源码/          微信原生小程序
├─ 2-网页版源码/          响应式单页面网页
└─ 3-智能课表解析服务/    PDF 文本提取 + 大模型课程结构化
```

主要功能：月历、周课表、日程、记账、主题壁纸、倒计时/正计时学习任务，以及学习时间与收支趋势统计；专注/休息时长可直接在计时任务页面调节。新用户首次进入为空日历，可自行添加日程或导入课表。课表仅接受办事大厅教务系统导出的 PDF，由服务端调用大模型识别课程、教师、教室、星期、节次与周次；不接收或保存西大账号密码。

使用前先为 `3-智能课表解析服务` 配置服务端环境变量并部署。网页版填写完整的 `/api/schedule/parse` 地址；小程序通过关联的微信云托管、云存储和云数据库异步导入 PDF，无需填写公网地址。模型密钥只保存在服务端，不能提交到仓库。
