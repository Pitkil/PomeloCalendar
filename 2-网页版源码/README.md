# 2. 单页面网页版源码

这是“西柚日历”的响应式单页面网页版，无框架、无构建步骤，浏览器直接打开即可运行。

## 运行

推荐在本目录启动静态服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。真实课表同步默认使用已部署的云端认证服务；也可以在“日历设置”中覆盖为自己的服务地址。直接双击 `index.html` 也能使用其他本地功能。

## 功能

- 月历、周课表、教学周和当天日程
- 日程增删改查、搜索、完成状态和冲突检测
- 番茄钟与自动专注记录
- 远端课表同步适配器和示例课表
- 主题、自定义壁纸与卡片透明度
- 本地离线存储、JSON 备份和 ICS 导出
- 桌面、平板和手机响应式布局
- 手动登录后导入课表（JSON、CSV 或制表符文本），适配学校验证码/滑块验证

## 远端同步接口

网页向设置的后端发送 `POST /api/swu/schedule`，请求体为：

```json
{
  "username": "学号",
  "password": "统一认证密码",
  "year": 2026,
  "term": 1
}
```

默认后端地址是 `https://swu-calendar-auth-314241-5-1488632993.sh.run.tcloudbase.com`，成功响应包含 `courses` 数组。密码只用于当次请求，不写入 localStorage，后端也不会保存密码或登录 Cookie。

## 手动登录后导入

如果学校统一认证要求验证码或滑块验证，在“同步课表”中展开“学校要求验证码？手动登录后导入”，点击链接完成教务系统登录，然后导出课表为 JSON/CSV，或复制表格内容并粘贴。支持的表头包括：课程名称、教师、星期（1-7 或 星期一）、节次、周次、教室。文件只在浏览器本地解析，不会上传。
