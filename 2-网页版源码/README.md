# 2. 单页面网页版源码

这是“西柚日历”的响应式单页面网页版，无框架、无构建步骤，浏览器直接打开即可运行。

## 运行

推荐在本目录启动静态服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。如需同步真实课表，另在 `3-认证后端源码` 中运行 `npm start`。直接双击 `index.html` 也能使用其他本地功能。

## 功能

- 月历、周课表、教学周和当天日程
- 日程增删改查、搜索、完成状态和冲突检测
- 番茄钟与自动专注记录
- 远端课表同步适配器和示例课表
- 主题、自定义壁纸与卡片透明度
- 本地离线存储、JSON 备份和 ICS 导出
- 桌面、平板和手机响应式布局

## 远端同步接口

网页向设置的后端发送 `POST /api/swu/schedule`，请求体为：

```json
{
  "username": "学号",
  "password": "统一认证密码",
  "year": 2026,
  "term": 1
}
```

默认后端地址是 `http://127.0.0.1:8787`，成功响应包含 `courses` 数组。密码只用于当次请求，不写入 localStorage，后端也不会保存密码或登录 Cookie。
