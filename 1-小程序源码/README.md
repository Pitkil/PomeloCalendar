# 1. 微信小程序源码

这是“西柚日历”的微信原生小程序版本，使用 WXML、WXSS 和 TypeScript。

## 导入方式

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件夹。
4. 如无正式 AppID，可使用测试号运行本地功能。

## 已实现功能

- 月历、周课表、日程列表和教学周显示
- 日程新增、查询、修改、删除与冲突检测
- 课程和个人日程分类展示
- 番茄钟、专注记录和每日统计
- 主题、壁纸、卡片透明度和专注时长设置
- 本地离线缓存
- 示例课表导入
- 可配置后端地址的西大课表同步入口

## 远端同步约定

小程序向配置的后端发送 `POST /api/swu/schedule`，请求体包含 `username`、`password`、`year` 和 `term`。后端应返回 `courses`、`schedule` 或 `res` 数组。密码只用于当次请求，小程序不会持久化保存。
